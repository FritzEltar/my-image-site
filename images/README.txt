把图片放进这个目录，然后双击 tools\update-gallery.cmd 重新生成 images.json。

目录层级 = 网站层级（三级）：

    images/全部/大图集1/角色1/001.jpg
           └大类┘└大图集┘└角色┘

    第 1 层  大类      网站首页的封面卡（只有一个大类时自动进入）
    第 2 层  大图集    网站上的图集封面卡，每个图集一张封面
    第 3 层  角色      图集内的页签（没有「全部」这一档）

特殊规则：

  · 图片直接放在图集文件夹下（没有角色子文件夹）
        images/全部/大图集1/还没分类.png
    会自动归入「草稿箱」，排在角色页签最后一位。

  · 想给图集换封面，在这个图集文件夹里放一张
        images/全部/大图集1/cover.jpg
    （也支持 cover.png / _cover.* / 封面.*）
    这个文件不会被当成图片显示。不放的话就用该图集的第一张图。

  · 第 4 层及更深会合并进角色名：
        images/全部/大图集1/角色1/服装/a.jpg  ->  角色「角色1/服装」

  · 想加新的大类，直接在 images/ 下建文件夹即可：
        images/新大类/图集A/角色1/a.jpg

文件夹名随便改，改完重跑一次脚本即可。

支持的格式：jpg / jpeg / png / gif / webp / avif / bmp / svg
（PureRef 的 .pur 文件不是图片，会被忽略）
